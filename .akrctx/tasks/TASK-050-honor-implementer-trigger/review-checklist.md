# Review Checklist

- [x] Goal is clear.
- [x] Canonical, legacy, disabled, and trigger semantics are explicit.
- [x] Workflow and reason are recorded.
- [x] Tests and validation commands are defined.
- [x] No unresolved questions remain.
- [ ] Failing tests cover resolved state and both recognized triggers.
- [ ] Runtime exposes a single resolved source of truth.
- [ ] All three root instruction renderings honor the trigger contract.
- [ ] Documentation and CLI output match the behavior.
- [ ] Full build, test, lint, init dry-run, and doctor validation pass.
- [ ] Protected installed instructions are changed only after exact-diff approval.
- [ ] Independent review is completed after implementation.
