# Acceptance Criteria

- AC-1: El informe compara las cuatro alternativas definidas en `plan.md`.
- AC-2: Cada alternativa distingue integridad, autenticidad y mera persistencia.
- AC-3: La recomendación liga cualquier receipt a snapshot, record, comandos, resultados, CLI y
  política, o explica por qué no debe existir.
- AC-4: El consentimiento de ejecución nunca se vuelve reutilizable automáticamente.
- AC-5: Se define revocación/invalidez cuando cambia cualquier parte de la frontera.
- AC-6: El wording propuesto no usa `valid` o `approved` como prueba de reejecución.
- AC-7: La recomendación incluye impacto de compatibilidad y migración.
- AC-8: No se cambia runtime antes de confirmación humana y cambio a workflow concreto.
- AC-9: Las validaciones documentales relevantes pasan antes del handoff de investigación.
