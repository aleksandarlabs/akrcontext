# Acceptance Criteria

- El informe compara las cuatro alternativas definidas en `plan.md`.
- Cada alternativa distingue integridad, autenticidad y mera persistencia.
- La recomendación liga cualquier receipt a snapshot, record, comandos, resultados, CLI y
  política, o explica por qué no debe existir.
- El consentimiento de ejecución nunca se vuelve reutilizable automáticamente.
- Se define revocación/invalidez cuando cambia cualquier parte de la frontera.
- El wording propuesto no usa `valid` o `approved` como prueba de reejecución.
- La recomendación incluye impacto de compatibilidad y migración.
- No se cambia runtime antes de confirmación humana y cambio a workflow concreto.
- Las validaciones documentales relevantes pasan antes del handoff de investigación.
