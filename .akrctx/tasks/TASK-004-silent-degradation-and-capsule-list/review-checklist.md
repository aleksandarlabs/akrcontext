## Review round 2

Both findings confirmed and fixed.

1. **`doctor --fix` re-invented the Codex target.** Reproduced on a Claude install with
   `targets` absent: `--fix` wrote `targets: ["codex"]` and reported readiness 100.
   `normalizeConfigForFix` now returns `undefined` when no target is recognizable and the
   caller skips the write, so the gap survives the repair. Re-verified: readiness stays
   97, the gap is still listed, and `targets` is left absent. The empty and
   unrecognizable variants already behaved correctly and are now pinned as regressions.
2. **The capsule list was canonical only for consumers.** `runTask` and
   `taskTemplateFiles` each carried their own copy, and the new test carried a third.
   Producers are now typed with `CapsuleContent = Record<CapsuleFile, string>` and
   `taskTemplateFiles` is derived from `capsuleFiles`; the tests iterate the constant.
   The drift this prevents is a build error, not a runtime one, so it was checked by
   adding a sixth entry and confirming both producers fail to compile.

## Notes for review

- `readConfigStrict` was removed rather than kept as an alias. Its semantics became the
  default, and leaving two names for one behavior would reintroduce the ambiguity this
  task closed.
- `setConfigValue` still falls back to `defaultConfig(["codex"])` when no config exists
  at all (`src/config.ts`). That is the same invented-target shape as defect (b) but on
  the *missing* path rather than the corrupt one, and it was left alone as out of scope.
  Worth a follow-up decision: `akrctx config set` on an uninitialized repo probably
  ought to refuse rather than materialize a codex install.
- `getInstalledTargets` marks a target installed when any one of its files exists
  (`src/doctor.ts`). On this repository that makes `doctor` believe Codex is installed
  because `AGENTS.md` is present, and `doctor --fix` would therefore install the full
  Codex skill set into a claude-only project. `akrctx upgrade` was used instead, since it
  honors `config.targets`. Recorded, not fixed here — it is finding (c) from the audit.
