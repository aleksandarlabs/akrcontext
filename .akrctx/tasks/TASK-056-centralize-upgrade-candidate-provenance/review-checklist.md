# Review Checklist

- [ ] El inventario de productores de candidatos es completo.
- [ ] El invariante de procedencia está expresado en una sola API.
- [ ] Todos los productores usan la nueva API.
- [ ] No queda propagación manual de `createdCandidate`.
- [ ] Archivos preexistentes y manipulados permanecen protegidos.
- [ ] Dry-run no persiste procedencia.
- [ ] La salida pública no cambia accidentalmente.
- [ ] La matriz de regresiones pasa.
- [ ] Los gates completos pasan.
- [ ] La frontera final está lista para revisión independiente.
