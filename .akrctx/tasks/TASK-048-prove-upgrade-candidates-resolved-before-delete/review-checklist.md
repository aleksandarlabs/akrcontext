# Review Checklist

- [x] Goal is clear.
- [x] Destructive boundary and scope are explicit.
- [x] Workflow and reason are recorded.
- [x] Edge cases and validation commands are defined.
- [x] No unresolved questions remain.
- [x] Failing tests cover disabled agents, removed targets, inventory changes, and foreign files.
- [x] Deletion requires both positive resolution evidence and durable akrctx provenance.
- [x] Dry-run and applied classifications match.
- [x] Existing partial-run and prior-version protections remain green.
- [x] Full build, test, lint, init dry-run, and doctor validation pass.
- [x] Existing protected instructions were not overwritten.
- [x] A foreign candidate matching destination bytes is preserved.
- [x] Preexisting foreign candidates are not adopted when a suggestion write is blocked.
- [x] Policy candidates created by `migratePolicy` are registered and cleanable after application.
- [x] The final boundary is ready for independent review.
