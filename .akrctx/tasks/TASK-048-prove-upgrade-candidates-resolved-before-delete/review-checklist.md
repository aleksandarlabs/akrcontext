# Review Checklist

- [x] Goal is clear.
- [x] Destructive boundary and scope are explicit.
- [x] Workflow and reason are recorded.
- [x] Edge cases and validation commands are defined.
- [x] No unresolved questions remain.
- [ ] Failing tests cover disabled agents, removed targets, inventory changes, and foreign files.
- [ ] Deletion requires positive, verifiable resolution evidence.
- [ ] Dry-run and applied classifications match.
- [ ] Existing partial-run and prior-version protections remain green.
- [ ] Full build, test, lint, init dry-run, and doctor validation pass.
- [ ] Existing protected instructions were not overwritten.
- [ ] Independent review is completed after implementation.
