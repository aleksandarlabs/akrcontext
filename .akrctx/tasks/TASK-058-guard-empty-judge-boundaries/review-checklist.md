# Review Checklist

- [x] La regresión reproduce el snapshot vacío accidental.
- [x] El comportamiento por defecto es fail-closed.
- [x] El rechazo no publica artefactos parciales.
- [x] El mensaje propone una recuperación correcta.
- [x] `--allow-empty` es explícito y auditable.
- [x] Snapshot ID y review record se distinguen en la UX.
- [x] Snapshots no vacíos conservan su comportamiento.
- [x] Salida humana y JSON están cubiertas.
- [x] Documentación y gates completos pasan.
- [x] La frontera final está lista para revisión independiente.
