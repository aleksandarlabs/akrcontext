# Review Checklist

- [ ] La regresión reproduce el snapshot vacío accidental.
- [ ] El comportamiento por defecto es fail-closed.
- [ ] El rechazo no publica artefactos parciales.
- [ ] El mensaje propone una recuperación correcta.
- [ ] `--allow-empty` es explícito y auditable.
- [ ] Snapshot ID y review record se distinguen en la UX.
- [ ] Snapshots no vacíos conservan su comportamiento.
- [ ] Salida humana y JSON están cubiertas.
- [ ] Documentación y gates completos pasan.
- [ ] La frontera final está lista para revisión independiente.
