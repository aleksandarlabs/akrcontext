  defines what counts as managed.
- `src/templates/wiki.ts` — `capsuleTemplates` holds the five capsule files, and
  `taskTemplateFiles` derives the `tasks/_template/<file>` paths from `capsuleFiles`.

  gets the current template and an upgraded one does not.
- `src/harness-files.ts` — `capsuleFiles`, the canonical capsule file list.
- `src/manifest.ts` — isManifestManagedPath excludes capsule templates today; extend only
  the canonical _template paths and test fresh-install provenance.
- `.akrctx/manifest.json` — schemaVersion 1; current capsule-template hashes are absent.
- `src/cli/upgrade.ts` — existing dry-run reporting; no new sync command is planned.
- `.akrctx/tasks/_template/acceptance-criteria.md` — the drifted file, regenerated by hand in
  TASK-075.
