# Review Checklist

- [ ] El fallo con `origin/main` está reproducido por una regresión.
- [ ] La base operativa se canonicaliza antes de capturar.
- [ ] La verificación no necesita refs simbólicas.
- [ ] Branch, remote ref, tag y hash están cubiertos.
- [ ] Bases inexistentes no dejan snapshots parciales.
- [ ] Compatibilidad legacy está definida y probada.
- [ ] Los digests y currency mantienen su rigor.
- [ ] No se mutan ni copian refs innecesariamente.
- [ ] Documentación y gates completos pasan.
- [ ] La frontera final está lista para revisión independiente.
