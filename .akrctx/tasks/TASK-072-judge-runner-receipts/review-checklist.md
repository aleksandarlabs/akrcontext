# Review Checklist

- [ ] Goal, contract and receipt shape recorded before implementation.
- [ ] Clarifications recorded; open questions left open, not guessed.
- [ ] Red tests written before implementation for binding invalidation and unbacked claims.
- [ ] Focused tests pass.
- [ ] Build, full tests, lint and required CLI checks run.
- [ ] Shipped instructions and docs describe one executor; installed files regenerated, not hand-edited.
- [ ] New pipeline measured with --timings and compared against the TASK-071 baseline.
- [ ] Transition path verified: a capsule reviewed under the old contract still verifies.
- [ ] Capsule ready for independent review; invocation requires user confirmation.
