# Review Checklist

- [x] Goal and evidence semantics are clear.
- [x] Workflow and reason are recorded.
- [x] Validation and compatibility cases are defined.
- [x] No unresolved questions remain.
- [ ] TDD workflows preserve ordered red→green evidence.
- [ ] Missing or incorrect red evidence is actionable.
- [ ] Non-TDD and legacy behavior remain compatible.
- [ ] All three implementer renderings agree.
- [ ] Full validation passes.
- [ ] Protected instructions follow approval policy.
- [ ] The final boundary is ready for independent review.
