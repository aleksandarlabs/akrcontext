# Workflows

## Doctor

Audit agent readiness and prepare future rules.

## Task

Create task capsule.

## Research-first

Use when task involves unknown tech, new libraries, auth, payments, security or migrations.

## SDD

Use for product features and broad behavior.

## TDD

Use for bugs, calculations, isolated business rules and regression-sensitive logic.

## UI Review

Use for screens, components, design fidelity and accessibility.
